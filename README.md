# 校园社交生活平台

项目使用微信原生小程序与微信云开发。当前第一阶段已实现校园首页、我的页面、微信身份建档、昵称与头像编辑；保留 QuickStart 页面便于排查基础云能力。

首次运行需创建 `users` 和 `account_ids` 集合、配置仅管理员读写权限，并部署 `cloudfunctions/userService`。基础操作见 [第一阶段部署与验收](docs/第一阶段部署与验收.md)，ID 号码占用集合和旧账号补齐见 [ID账号部署与补齐](docs/ID账号部署与补齐.md)。尚未部署时首页仍可浏览，但不能登录或保存资料。

本地测试：`node --test tests/user-service.test.js tests/user-client.test.js`。测试不会连接真实云环境。

后续页面开发默认遵循[页面加载与切换约定](AGENTS.md)：优先展示会话内已有资料，按需后台更新，减少重复登录检查、整页等待和切换跳变。

动态广场已接入专属文字发布页、动态卡片和底部评论面板，以及真实点赞、转发、回复。当前不设置独立动态详情页，长文直接在卡片内展开，分享打开首页展示对应动态。卡片右上使用“关注”样式按钮（暂未开放功能）和两条杠菜单，支持本人删除、他人举报。普通登录用户无需学校认证即可参与；校园圈、跑腿和集市保留认证限制。新增集合、索引和云函数部署步骤见[动态广场部署与验收](docs/动态广场部署与验收.md)。

角色权限阶段已接入普通用户、学生、管理员身份展示，以及有服务端权限校验的基础管理工作台。升级部署、旧数据兼容与双账号验收见 [角色权限与管理员工作台](docs/角色权限与管理员工作台.md)。

学校认证申请已实现填写信息、选择材料、提交及本人查询，包含并发重复提交保护。部署前需创建申请集合、配置私有材料存储，再开启上传；详见 [学校认证申请部署与验收](docs/学校认证申请部署与验收.md)。

管理员学校认证审核已接入列表、详情、私有材料查看、通过与驳回；通过后同步学生身份和学校，驳回后允许修改材料重提。部署需新增审核记录集合、申请列表索引并更新 `userService`，详见 [学校认证审核部署与验收](docs/学校认证审核部署与验收.md)。完整本地测试：`node --test`。

学校认证页支持待审核时“取消认证”和通过后“撤回认证”。操作需二次确认；成功后恢复未认证普通用户、清空学校归属，并允许重新申请。管理端刷新后不显示已撤回申请，旧详情、材料和审核请求也会被拒绝。部署及双账号验收见 [学校认证撤回部署与验收](docs/学校认证撤回部署与验收.md)。

## 保留的云开发 quickstart 说明

这是云开发的快速启动指引，其中演示了如何上手使用云开发的三大基础能力：

- 数据库：一个既可在小程序前端操作，也能在云函数中读写的 JSON 文档型数据库
- 文件存储：在小程序前端直接上传/下载云端文件，在云开发控制台可视化管理
- 云函数：在云端运行的代码，微信私有协议天然鉴权，开发者只需编写业务逻辑代码
