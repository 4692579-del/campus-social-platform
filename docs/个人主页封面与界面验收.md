# 个人主页封面与界面

“我的”页采用自定义顶部导航。封面从状态栏开始覆盖整个顶部，并额外延伸 260rpx；默认是中性色背景，没有虚构人物照片。头像压在封面下沿。其他页面继续使用原有蓝色顶部栏。

## 本次实现

- 已登录用户点击“设置封面 / 更换封面”选取相册图片，压缩并检查大小（最多 5MB），上传后保存至本人 `users.coverFileID`。重新登录、换设备后从服务端读取。
- 封面使用现有公开头像目录 `avatars/用户ID/cover-文件名`，复用创建者写入规则。封面是公开个人资料图片，不要上传认证证件。未更改私有认证材料规则。
- `updateCover` 使用云端可信微信身份，只接受当前环境、当前用户目录内的封面图片；仅修改封面，不覆盖昵称、头像、角色或认证。
- 暂时没有关注与粉丝业务，两项数量都从 0 开始；没有加入虚构用户名、学号、简介、内容列表或统计量。
- 加入年月只显示账号真实 `createdAt`，没有日期或日期无效时隐藏。昵称、头像、认证和学校取已有用户资料。
- 未认证显示“去认证”，待审核显示“查看审核”，驳回后显示“重新认证”。认证学生显示认证标记、真实学校和“分享个人资料”。认证状态文字仍可进入申请详情，包含取消与撤回入口。管理员保留工作台入口。
- 内容选项依次为“动态 / 回复 / 转发 / 收藏”，使用动态、对话、双箭头和书签图标。只显示当前选中项的文字，切换后显示对应空状态。
- 关注、粉丝、动态、回复、转发、收藏及个人主页分享的实际业务留待后续实现。“分享个人资料”暂时只提示后续开放，不生成指向本人页面的假分享链接。

## 部署及检查

需要更新 `userService` 云函数，以启用 `updateCover` 并返回 `coverFileID`、`createdAt`；无需新建集合或修改已有存储权限。前端重新编译后可看到新版个人主页。

旧云函数仍可登录和读取认证，但无法保存封面；页面会明确提示更新云函数，不伪装保存成功。

手动验收：

1. 未登录时查看封面默认区域和登录按钮；登录后设置封面，退出重新登录确认保留。
2. 换另一个账号登录，确认不会显示上一账号的封面；取消相册选择时没有错误提示。
3. 更改头像或昵称后，确认封面仍在；封面更新不影响认证与学校。
4. 分别核对未认证、待审核、已认证、已驳回、管理员的按钮和入口。
5. 依次点击四个内容选项，确认只有一个文字标签和对应选中线；关注与粉丝为 0。
6. 在不同设备上确认封面覆盖状态栏与胶囊所在区域，头像与封面重叠，底部导航不遮住内容。

本次以本地自动化测试和静态检查验收，未使用 Computer Use 操作界面或上传用户照片。

# 沉浸式封面与滚动导航（最新调整）

- 个人主页使用独立 `scroll-view` 和 `navigationStyle: custom`，由 `bindscroll` 驱动固定导航；关闭原生页面滚动及整页下拉回弹，避免固定导航与被拉下的封面重复。
- 保留原封面尺寸（导航高度 + 260rpx）及资料加载方式；新增封面导航副本和 CSS 模糊层，避免滚动到白色资料区后透出白色背景。
- 模糊层、深色遮罩和标题按当前位置双向计算。封面及大标题位置通过实际布局测量；尺寸变化、昵称换行或资料更新后重新测量。
- 每帧合并小数据更新，完全折叠后的稳定区不继续重复 `setData`。页面离开时取消未完成的帧与测量回调。
- 返回按钮保持返回首页，搜索按钮恢复并进入现有搜索页；两者以实际微信胶囊位置留出间隔。个人主页依旧不显示底部导航栏。
- CSS `filter` 可用时叠加同一封面的模糊图；不支持时保留原封面色彩及深色遮罩降级，导航始终有独立背景，不透出下方白色内容。
- 两行紧凑标题使用真实昵称与本人已发布广场动态总数。本人列表接口增加只读 `total` 返回值，复用现有集合、身份校验和索引；不修改数据库记录或发布、删除、认证逻辑。未得到完整总数时先显示“帖子”，不把分页条数冒充总数。

部署：重新部署整个 `cloudfunctions/userService`，再编译小程序；无需新建集合或索引。仅编译前端也能使用滚动效果，但旧版接口在列表未加载完整时不会显示总数。

验收：在 iOS、Android 各检查一次。顶部应保持清晰封面与透明外观；上滑至封面离屏时固定导航保持封面色彩与深色模糊；大标题越过导航时紧凑标题淡入；向下回到零位置全部恢复。连续往返、快速滑动、旋转或调整设备尺寸时，返回与搜索按钮不移位、不覆盖微信胶囊。无封面、封面加载失败、超长昵称、0 条帖子及超过一页的帖子都应正常展示。

本地 257 项测试通过，覆盖滚动阈值、双向恢复、帧合并、过期回调、真实总数及原有资料/帖子逻辑。已在微信开发者工具模拟器确认清晰封面、深色模糊导航、紧凑标题、反向恢复及搜索按钮跳转；iOS、Android 真机仍需分别验收。

## 个人主页下拉刷新（2026-11-18）

- 到顶部后继续下拉，仅白色资料、头像与帖子区域移动；封面和固定导航不移动。封面图片预留下拉空间，导航副本与原图使用同一尺寸及裁切，保持画面连续。
- 刷新指示器在封面中间显示，旋转角度与下拉距离对应。松手后白色区域以 220ms 过渡复位；不足阈值不请求，超过阈值刷新本人动态并持续转圈至读取结束。
- 复用正在读取的请求，刷新时保留已有资料和动态。离开页面、取消手势、切换账号均清理下拉状态；迟到的旧请求不干扰新一轮刷新。
- 新增测试覆盖下拉阈值、旋转、复位、重复请求、取消与过期回调、拖动中的标题测量。开发者工具模拟器已确认下拉刷新、松手复位、正常上滑折叠和反向恢复。真机触摸与系统回弹仍需 iOS、Android 各检查一次。
- 本次下拉修复仅需重新编译小程序，不增加云端部署、集合或索引。

## 快速回顶状态校准（2026-11-18）

- 滚动停止、触达顶部及再次触摸时，通过容器偏移与实际封面坐标核对滚动位置，恢复导航透明状态，不单独依赖最后一次滚动事件。惯性仍在移动时继续核对，位置稳定或到顶后停止；不会强制把停在中部的页面跳回顶部。
- 手势可从内容区开始，回到顶部后继续下拉；回顶前的位移不计入刷新距离。取消、离开页面时清理定时器及查询，旧查询不能覆盖新一轮滚动状态。
- 顶部仅展示原封面，导航保留渐变模糊层；清晰封面副本已移除，避免回顶拼接细缝。
- 本地 267 项测试通过，覆盖漏掉最终回顶事件、原生偏移记录滞后、惯性持续移动、迟到查询与同次手势回顶后刷新。开发者工具模拟器确认快速往返后恢复清晰封面，并能再次触发下拉刷新；iOS、Android 真机仍需验收。本次仅需编译前端。
