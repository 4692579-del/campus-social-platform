# 全球新闻部署与验收

## 部署

1. 在项目现用的 `campus-social-dev-d3dmcsfefdcae4` 微信云开发环境创建下表集合。每个集合都设置为仅管理员可读写，客户端统一通过 `userService`。已有普通动态集合和规则无需迁移。

   | 集合 | 用途 | 普通复合索引（非唯一） |
   | --- | --- | --- |
   | `news_cache` | 列表分页快照、详情请求租约、上游限流 | 主键即可 |
   | `news_articles` | 标题、正文、来源、配图及公开互动计数 | 主键即可 |
   | `news_interactions` | 每个账号的新闻点赞和收藏状态 | `userId` 升序、`active` 升序、`postId` 升序 |
   | `news_replies` | 新闻一级评论 | `postId` 升序、`status` 升序、`sortKey` 降序 |
   | `news_reply_children` | 新闻楼中回复 | `postId` 升序、`rootId` 升序、`status` 升序、`sortKey` 升序 |
   | `news_comment_states` | 评论点赞和个人心碎状态 | 主键即可 |
   | `news_reports` | 新闻及评论举报 | 主键即可 |

2. 在微信开发者工具的云开发控制台进入「云函数 → userService → 编辑配置 → 环境变量」，添加 `WORLD_NEWS_API_KEY`。值取自 World News API 控制台。仅保存在云函数变量中，保留其余变量。当前功能使用现有 Node.js 运行时及原有依赖，`userService` 超时时间继续使用 60 秒。
3. 部署整个 `cloudfunctions/userService`，重新编译小程序。搜索页的「探索」进入 `pages/global-news/index`，默认 `en`。要验收中文，可在开发工具以 `pages/global-news/index?language=zh` 启动。公开发布前请按套餐要求提供服务商署名或链接，并确认所展示的全文和配图具备相应授权。 [套餐](https://worldnewsapi.com/pricing/) · [服务条款](https://worldnewsapi.com/terms/)

## 行为

- 列表始终使用 `search-news`，按 `publish-time` 倒序，默认英语且不限来源国家。每页 10 条，分页使用同一发布时间上界和 `offset`。先按第三方新闻 ID 和规范化网址去重，后续页在客户端继续去重。列表云端缓存 20 分钟。刷新重新检查缓存，仍在有效期内时直接复用。 [Search News](https://worldnewsapi.com/docs/search-news/)
- 详情优先读文章缓存，正文缺失时请求 `retrieve-news`，需要配图或补充正文时再请求 `extract-news`。提取接口的图片顺序用于复用的图片轮播。接口未返回正文锚点时统一显示在正文下方。正文保留换行，缺失时显示已有摘要和复制原文链接。外链图片使用现有加载失败占位。 [Retrieve News](https://worldnewsapi.com/docs/retrieve-news/) · [Extract News](https://worldnewsapi.com/docs/extract-news/)
- API 请求在整个云环境限制为每秒最多一次且同时最多一次。402 暂停到 UTC 次日零点，429 暂停一分钟。异常时展示同页缓存与错误原因，首次无缓存时显示可重试错误。 [额度与速率限制](https://worldnewsapi.com/docs/quotas-and-rate-limiting/)
- 点赞、收藏、评论、楼中回复及举报沿用可信微信会话。新闻评论同样走已有文字审核和用户图片处理。新闻来源头像是站点标识，新闻不进入个人动态、个人回复时间线或动态广场搜索。新闻卡片的第三个操作是收藏，新闻评论暂不提供「问问小萃」。

## 联调

1. 从搜索页「全网热榜」点击「探索」。进入「全球新闻」后检查真实来源名称、标题、摘要、时间和封面。上下滑动并加载下一页，确认重复文章不出现。
2. 打开一篇长文章，确认完整标题、分段正文和原文链接。打开封面及多图大图，确认个别外链失败时正文仍可读取。返回后确认新闻列表仍在原滚动位置。
3. 用两个普通账号验证新闻点赞、收藏、一级评论和回复。重新进详情确认收藏仅对本人可见。检查普通动态的帖子、互动及评论未出现新闻记录。
4. 下拉刷新、返回再进入，检查缓存及列表状态。配置 `WORLD_NEWS_API_KEY` 后再验收真实 API 与真机图片。401、402、429、超时和空列表可用自动化测试复验。
