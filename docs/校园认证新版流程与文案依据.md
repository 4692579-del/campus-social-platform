# 校园认证新版流程与文案依据

## 页面流程

“我的 → 去认证 / 重新认证”进入认证介绍页，只保留个人证件认证，不提供学校邮箱认证。

流程为：认证介绍 → 选择学校 → 搜索学校 → 确认学校 → 填写姓名学号与上传材料 → 提交 → 查看审核状态。搜索仅提供“闽南科技学院”，支持部分名称匹配、匹配文字蓝色高亮、清空和取消。没有选中当前可用学校时不能进入下一步。旧版其他学校的申请仍可查看，驳回后重新申请需选择当前可用学校。

上传页使用蓝色主题，包含材料上传、图片预览、拍摄示例、资料填写和用途确认。示例仅为抽象示意图，没有生成虚构证件或学生资料。姓名、学号和材料沿用既有云端校验及私有存储流程。

审核中和已通过的账号直接进入认证状态页，保留刷新、取消申请、撤回认证。取消或撤回后清空旧草稿并返回介绍页，可重新开始申请。返回前一步不丢失当前尚未提交的材料草稿；离开整个页面仍会清理内存材料。
