# 搜索功能部署与验收

## 部署

1. 对整个 `cloudfunctions/userService` 执行“上传并部署：云端安装依赖”。本次新增 `square-search.js` 及 `searchSquareContent` 分发，不能只上传前端或单独一个 JS 文件。
2. 重新编译小程序。新增 `pages/search-results/index` 已注册到 `app.json`，需要完整编译；底部搜索仍使用原生标签页 `pages/search/index`。
3. 保留 `square_posts` 既有普通索引：`posts_square_feed`（`scope` 升序、`status` 升序、`sortKey` 降序）和 `posts_by_author`（`authorId` 升序、`scope` 升序、`status` 升序、`sortKey` 降序）。用户查询建议增加普通复合索引 `users_active_search`：`status` 升序、`role` 升序、`_id` 降序，用于账号过滤和稳定分页。已有相同字段顺序的索引无需重复添加。
4. 无新增集合、环境变量或存储权限。客户端继续只通过云函数读取用户，不开放 `users` 集合读权限。

关键词先转义为普通文本，再由 CloudBase `db.RegExp` 执行不区分大小写的包含查询；不是全文相关度搜索。索引辅助板块、作者、状态和排序条件，不能把正文/昵称的任意包含匹配变成全文索引；无需为长正文额外建立普通索引。数据规模扩大后需评估专门的全文检索服务。参考 [CloudBase 数据库 API](https://docs.cloudbase.net/api-reference/webv3/database) 与 [索引管理](https://docs.cloudbase.net/database/data-index)。

## 当前行为

- 本人或他人主页搜索入口通过 `services/user.js` 的短时会话交接进入同一个底部搜索页；带灰色 `@8位ID` 胶囊，X 在胶囊内部。普通底栏入口恢复无作者条件的搜索，切换账号清理旧条件。
- 只带 ID、不输入文字，提交后默认打开“用户”栏，显示该真实账号；切到“动态广场”可查看该账号已发布广场动态。有关键词时默认打开“动态广场”，只匹配该作者自己填写的正文，含引用的帖子也不匹配被引用者正文。
- 带 ID 时“用户”栏始终指向该账号；删掉胶囊后恢复全局搜索，动态按正文查询，用户按昵称或公开 ID 查询。正文或用户名中的 `.*`、括号、竖线等作为普通文字匹配。全空条件不查询，不伪造热门词或结果。
- “校园圈”只保留入口和未开放提示，不请求校园内容。用户及指定作者搜索需登录，普通未认证登录用户可用；全局广场动态搜索沿用游客可浏览规则。
- 提交才查询，不在逐字输入时调用云端。结果页独立，顶部三个标签共用索引驱动内容与主题蓝指示条；切标签保留动态卡片、图片和各栏滚动节点。动态复用 `square-post` 及现有详情、点赞、回复和引用，用户行进入真实个人主页。
- 会话内按关键词、作者和类型缓存并合并相同请求；先预填真实缓存，后台更新不清屏。新条件、隐藏、退出和切账号隔离迟到响应；分页与点赞、删除共享缓存同步。

## 验收

1. 从本人及他人主页分别点搜索，检查胶囊 ID 正确。空关键词提交应显示对应用户；关键词提交只出现该作者正文包含关键词的已发布广场动态。
2. 点击胶囊内 X，使用相同关键词应能搜其他作者。返回搜索页再从底栏重新进入，应无旧作者条件；返回结果页则保留当前查询草稿。
3. 普通搜索输入昵称、完整 ID 或 `@ID`，切到“用户”，应能进入对应真实主页。未认证账号同样可用，封禁账号不在结果中，不返回生日、实名、认证材料或其他私有资料。
4. 广场结果检查普通动态、引用、单图/多图、点赞、评论、引用及删除；发布后刷新查询，结果按真实时间倒序。连续加载分页不重复；用户匹配昵称和 ID 时同一人只显示一次。
5. 快速更改关键词、切三个标签、进入主页返回、切换账号，旧查询不能覆盖新条件。图片预览及评论选图返回保留节点，后台更新不重设图片源。
6. 模拟云函数未部署、网络失败、目标失效或缺少索引，显示真实错误并可重试；不能把请求失败显示成“没有结果”。校园圈只提示未开放。

本地自动化测试不连接真实云环境。云端权限、索引和真机原生输入/导航需在部署后按以上步骤验收。
