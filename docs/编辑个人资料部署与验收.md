# 编辑个人资料：部署与验收

## 界面与行为

- 白色顶部显示“取消 / 编辑个人资料 / 完成”，避开微信胶囊区域。未修改内容时“完成”不可点。
- 封面右下角的“更换封面”与主页使用相同的半透明圆角样式；头像上有相机加号，点击使用微信头像选择能力。
- “姓名”编辑的是原有昵称，不修改认证申请中的真实姓名。
- 简介最多 160 个字，支持换行。保存后显示在个人主页昵称下方、加入日期之前；简介为空时不占位。
- 保留“位置”入口，点击只提示暂未开放；不请求定位，不写入虚构位置。没有网站栏。
- 出生日期可选择、修改和清空，范围为 1900-01-01 至今天；生日暂不展示在主页。
- 编辑过程中的封面、头像和文字均为草稿；点“完成”才上传新图片并一次提交资料更新。“取消”退出编辑页，不保存修改。
- 若图片已上传但保存请求超时，保留文件 ID 供重试，避免反复上传；不在结果不确定时删除云文件。

## 由项目所有者手动部署

本次只修改本地代码，不操作云端部署，也不改变环境变量、集合或存储权限。

1. 打开当前项目，确认 `cloudfunctions` 旁边的当前环境为 `campus-social-dev`（环境 ID 为 `campus-social-dev-d3dmcsfefdcae4`）。
2. 在左侧展开 `cloudfunctions`，右键 **userService 文件夹**，不是 `index.js` 文件。
3. 选择 **“上传并部署：云端安装依赖（不上传 node_modules）”**。部分版本显示为“创建并部署：云端安装依赖”。
4. 等待提示部署成功，再重新编译小程序。测试手机也要重新打开更新后的预览包。

本次更新 `userService/service.js` 中的资料字段校验与返回字段：`bio`、`birthDate`，并允许编辑表单原子保存 `coverFileID`。无需手动在 `users` 中创建字段；首次保存时自动写入。旧客户端不提交的新字段会保留，不会被清空。

不要替换现有环境或重新创建数据库；保留现有头像公开读取和创建者写入规则、认证材料私有规则、认证上传开关及超时配置。

## 手动验收

1. 进入“我的 → 编辑个人资料”，确认昵称、封面、头像及已有简介、生日正确预填。
2. 点击头像相机图标更换头像，修改昵称、简介和出生日期，点“完成”。主页应显示新头像和简介；退出重新登录后仍保留。
3. 更换封面后点“取消”，主页封面保持原样；再次编辑并点“完成”，封面才更新。
4. 简介清空后保存，主页不再显示简介；出生日期清空后重新进入编辑页应为空。
5. “位置”只提示未开放，没有网站栏。主页不显示出生日期。
6. 确认普通用户、学生、管理员修改个人资料均不改变角色、学校和认证结果。

本次未使用 Computer Use 检查，不代替用户部署云函数、提交 Git 或发布正式版本。
