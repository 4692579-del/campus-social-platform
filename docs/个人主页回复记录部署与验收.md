# 个人主页回复记录

“回复”展示当前登录账号在动态广场发出的一级评论及楼中回复，按发布时间倒序排列。直接上文显示摘要，自己的回复完整展示，沿用现有评论区的视觉和操作。小萃生成的回复不混入本人记录。

## 部署

1. 增加两个普通、非唯一复合索引，已有同字段索引可复用：

   | 集合 | 索引名称 | 字段顺序 |
   | --- | --- | --- |
   | `square_replies` | `own_reply_history` | `authorId` 升序、`scope` 升序、`status` 升序、`sortKey` 降序 |
   | `square_reply_children` | `own_child_history` | `authorId` 升序、`scope` 升序、`status` 升序、`sortKey` 降序 |

   定位窗口沿用 `children_by_root`：`postId` 升序、`rootId` 升序、`status` 升序、`sortKey` 升序。保留原有索引。

2. 等待索引生效，右键整个 `cloudfunctions/userService` → **上传并部署：云端安装依赖**，包含新增的 `square-history.js` 及更新后的 `square.js`、`service.js`。
3. 重新编译小程序。无需新增集合、环境变量或修改数据库/存储权限，评论集合继续仅管理员可读写。

新增 `listSquareOwnReplies` 和 `getSquareReplyContext`，身份由云函数可信会话取得，不能通过客户端作者字段切换查询对象。上文和作者资料批量读取，不返回私有原图路径、openid、内部任务及作者数据库 ID。

## 验收

- 普通未认证账号分别发送一级评论、楼中回复、带图回复和带图问小萃；个人主页显示本人记录，最新在前。配图沿用160rpx正方形、18rpx圆角及12rpx间距，最多三张同行。机器人输出不计入本人历史。
- 上文最多显示两行摘要及图片数量，自己的回复完整展示。点击记录进入原动态并定位、高亮对应评论，不自动弹键盘；点击“回复”才打开现有面板并选中对象，保留50字、三张图片和问小萃的规则。
- 用超过20条一级评论、超过60条楼中回复验证深处定位。目标组显示目标所在窗口，可“查看更早的回复”或“展开更多回复”；普通评论区原有折叠方式不变。
- 标签切换保留原节点及横向过渡。进入和返回优先展示真实会话缓存，过期后台更新；读取失败保留内容、允许重试。触底加载历史，下拉刷新当前回复标签。
- 本人菜单确认删除成功后才移除，失败仍保留。删除一级评论隐藏整组历史，删除中间楼中回复只隐藏该条，其余回复显示上文不可用。原动态删除或不可见时不展示关联记录。
- 个人心碎折叠只影响当前账号，历史和定位不能绕过已折叠上文。到原讨论恢复后，返回刷新可重新显示。
- 发送、删除、点赞及心碎同步会话缓存；退出或换账号清理。让查询、定位或操作在账号变更后返回，不能恢复旧内容或弹出旧输入框。

自动化测试覆盖可信身份、双集合游标分页、空页推进、删除及折叠可见性、深层定位、缓存与迟到响应、输入聚焦边界、组件操作。WXML/WXSS使用微信原生编译器检查；真实索引、云部署和真机交互仍需按以上步骤验收。
