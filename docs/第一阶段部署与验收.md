# 第一阶段部署与验收

本阶段完成黄色主题首页、“我的”、当前用户登录建档及昵称头像编辑。学校认证、信用管理、内容审核和其他业务将在后续阶段实现。首页的“即将开放”卡片仅说明后续功能，不提供虚假的业务数据。

## 一次性部署

1. 在微信开发者工具中确认 `cloudfunctions` 当前环境为 `campus-social-dev`。`app.js` 已保留该环境 ID。
2. 打开云开发控制台 → 数据库，创建文档型集合 `users`，不必手动新增用户记录。
3. 把 `users` 集合权限设置为“仅管理员可读写”。如果界面使用自定义安全规则，填写：

   ```json
   { "read": false, "write": false }
   ```

   小程序通过云函数访问，服务端 SDK 仍能读写。不要把用户集合设置为所有人可读写，也不要设置为创建者可任意写，否则用户可能绕过资料接口修改角色、认证等字段。
4. 回到代码目录，右键新增的 `cloudfunctions/userService`，选择“创建并部署：云端安装依赖（不上传 node_modules）”，等待成功。原来的 `quickstartFunctions` 保留，无需重新部署。
5. 云存储维持“所有用户可读、仅创建者可写”或更严格的规则，不要开放所有人可写。头像由客户端上传至 `avatars/当前用户ID/`，资料接口只接受本环境当前用户目录中的图片 fileID。后续公开个人主页时需一起复查头像访问规则。
6. 重新编译小程序。普通编译将进入“校园”首页，底部有“校园”和“我的”两个入口。

基础库需支持 `chooseAvatar` 与昵称填写能力（最低 2.21.2）。当前本机私有配置为 3.18.0；公共配置仍是旧模板的 2.20.1，已更新为 3.18.0，便于其他电脑使用一致版本。

## 验收顺序

| 操作 | 预期结果 |
| --- | --- |
| 首次打开首页 | 黄色欢迎区，无模拟帖子；尚未开放的模块有文字标识 |
| 点击“去登录” | 切换至“我的”，显示微信登录按钮 |
| 点击微信登录 | 创建自己的 users 记录，显示“校园新同学”和“未认证” |
| 重复点击登录或退出后重新登录 | 仍复用同一条记录，不覆盖已保存昵称和头像 |
| 编辑昵称、选择头像并保存 | 返回“我的”，显示最新资料 |
| 切回首页 | 昵称同步更新 |
| 重新编译后进入“我的” | 从云端恢复已保存资料 |
| 保存空白或超过20字的昵称 | 显示校验提示，资料不保存 |
| 上传或调用失败 | 显示错误并允许重试，不提示保存成功 |
| 从控制台暂将测试账号 status 改为 banned 后重试 | 云函数拒绝登录、读取和修改；测试后将 status 恢复 active |

头像选择请在真机预览再验一次，模拟器无法完全替代微信头像昵称填写流程。真实发布前，需在微信公众平台按照实际收集的个人信息配置隐私保护指引；本阶段不接入手机号、位置或学校证件。

## 数据与权限

`users` 使用 OpenID 的 SHA-256 摘要生成固定主键；云函数新增记录使用数据库主键唯一约束，处理并发首次登录。内部保存 `openid`、`role=user`、`status=active`、学校与认证状态，以及服务端创建和更新时间。前端只接收展示所需字段和服务端确认的角色。第一阶段曾使用的 `role=student` 默认值已修正，旧数据处理见 [角色权限与管理员工作台](角色权限与管理员工作台.md)。

客户端不能决定登录身份，云函数始终读取 `cloud.getWXContext().OPENID`。`updateProfile` 按当前身份定位记录，仅允许 `nickname` 和 `avatarFileID` 两项；学校、角色、认证等不在可修改范围内。

本地仅保存“曾登录”标记，不把缓存当作服务端权限。退出登录只退出本平台界面状态，保留账号资料，不注销微信本身的身份。重新进入时会读取云端资料；服务不可用时显示重试入口。

头像旧文件和保存结果不明时的新文件暂不自动删除，避免请求超时后误删已绑定的头像。长期使用前需增加文件清理策略。昵称和头像尚未接入独立的 AI 审核，当前用于毕业设计开发测试，不代表内容治理已完成。

## 本地检查

无需安装依赖，在项目根目录执行：

```text
node --test tests/user-service.test.js tests/user-client.test.js
```

测试使用内存数据库与模拟微信接口，不访问真实云环境。云数据库权限和真实上传效果必须按上面的步骤在测试环境验收。

QuickStart 原页面仍在 `pages/index/index` 和 `pages/example/index`，可在开发者工具添加对应编译路径单独打开，不放入面向学生的日常入口。
