# 动态引用

第三个互动图标现在可以引用原动态：在来源页打开共用发布面板，原帖全文、作者、配图和声明显示在圆角虚线框中。预览卡片右上角通过裁掉边框形成真实断口，X位于断口处；移除时只删除引用，保留本人输入及本次选图。发布后沿用同款卡片，边框闭合、不带X，点击进入被引用动态的详情。

## 部署

1. 右键整个 `cloudfunctions/userService` → **上传并部署：云端安装依赖**，包含新增的 `square-quotes.js` 及更新的 `square.js`。
2. 重新编译小程序。新增 `components/quote-card` 已注册到动态卡片和发布组件，详情页也注册了共用发布组件。
3. 不新增集合、复合索引、环境变量或存储权限。引用关系保存在既有 `square_posts.quotePostId`，数量保存在原动态的 `quoteCount`；不启用旧的转发互动接口。

## 规则

- 普通未认证登录账号可以引用已发布的广场动态。客户端只提交 `quotePostId`，不接受客户端引用快照；云端检查来源为真实可见的 `square` 动态，并在发布事务内再次确认。校园圈、私有资料或已删除动态不能从该入口绕过权限。
- 只附引用也可以发布；本次另写的正文仍最多150个Unicode码点，另选图片最多9张。原文和原图不进入本人的输入框、不占用新增文字和图片名额，也不复制到本人相册。
- 只有新写文字会走现有文字审核，新上传图片沿用当前的私有上传和公开成品流程。引用只读取原动态已保存的公开成品，不返回私有原件路径。
- 同一发布请求的正文、声明、图片源及引用ID必须一致；重复请求只生成一条动态、增加一次引用数。删除引用动态和减少原帖引用数在同一事务完成，重复删除不会重复扣减。成功提交后原帖被删除，仍可确认同一请求的成功结果，引用框显示不可用。
- 原动态删除后不保留失效的内容快照。云端重新读取返回不可用框；客户端已确认删除时同步清理当前缓存中的引用投影，迟到列表不能恢复正文或图片。
- 引用链按需批量读取，最多完整展示三层，更早内容显示可进入原详情的入口，防止无限嵌套。作者资料读取当前公开资料。
- 草稿只在明确保存时记录引用ID，与本人的文案、声明和选图一起恢复；不保存引用原文快照。新引用入口可带入已有草稿，移除或切换引用会更新提交ID，取消仍使用既有三选项确认。退出、切账号或移除后，迟到读取不会恢复旧引用或覆盖正文。
- 发布面板中的引用预览使用独立滚动区域；正文textarea保持现有原生焦点、回车和键盘规则，不嵌入纵向scroll-view、不通过行数调整高度。
- 小萃暂不读取引用原文、引用配图及引用链，只使用本次实际输入和选图；只有引用时不出现优化入口。
- 不增加个人主页专门的引用记录列表，原“转发”标签保持未开放。引用发布本身是一条新的本人动态，沿用已有“动态”列表展示。分享图标仍为静态占位。

## 验收

1. 登录后在首页点击引用图标，原位出现发布面板和完整引用卡片；取消后回到原滚动位置。验证X位于边框断口而非框内，能一次移除整个引用，且不会清空自己的文案、选图或重新请求键盘。
2. 分别仅引用、引用加文字、引用加图片、引用加图文发布；新动态显示正确引用卡片，自己新添的图片与原帖图片分开，原帖引用数量真实增加。点击新动态正文进入新动态详情，点击框内内容进入原动态详情。
3. 保存引用草稿、退出重进、重新选择其他引用、移除引用并取消，核对草稿和提交标识。网络读取失败保留已缓存的真实预览并提示重试；没有缓存时显示读取失败，不能伪称原帖已删除。已确认删除或不可见时需移除引用才可发布。
4. 重复提交和重复删除验证数量只变一次；让原动态在审核或上传期间被删除，发布事务必须拒绝且不增加引用数量。让已成功请求在原动态删除后重试，能确认原结果、不重复计数。
5. 原动态带多图、较长旧正文、声明及引用链时，验证全文、配图顺序、左右滑动、返回保留页码与详情入口。发布预览较高时可以在独立区域滚动查看，输入框继续正常输入。
6. 引用原文包含不同文案、配图时，调用小萃优化只处理本次新增内容；评论问小萃也不获得被引用图片。退出/换账号和移除引用时的迟到响应不得恢复旧内容。

本地自动化覆盖服务端真实引用、事务与去重、来源失效、图片隔离、引用链、草稿、账号隔离、缓存删除、计数同步及引用卡片跳转。云端部署及真机键盘、滑动效果仍需按以上步骤验收。
