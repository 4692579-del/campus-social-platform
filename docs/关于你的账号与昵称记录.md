# 关于你的账号与昵称记录

个人主页点击“加入日期”或右侧箭头，进入“关于你的账号”。页面展示当前账号的头像、昵称、ID账号、认证学校、加入日期、用户名更改次数和上次更改时间。ID账号在信息列表第一项，点击复制；账号所在地已移除。学校名称从个人主页移到这里，主页保留认证标识。

当前系统没有独立的 @用户名，“用户名更改”统计的是编辑个人资料时对昵称的修改。只统计成功写入云端的实际变化；保存相同昵称、修改头像/简介/生日/封面均不增加次数。昵称、次数、最后修改时间在同一事务中写入，失败时一起回滚。

新建账号从建档时开始完整记录。旧账号没有保存过去的改名历史，首次读取账号信息或保存资料时启用记录；页面不展示统计起点提示。不能从 updatedAt 还原过去的次数或时间。时间由云端生成，页面按中国标准时间显示。

统计保存在现有 users 集合中：nicknameChangeCount、nicknameLastChangedAt、nicknameTrackingStartedAt、nicknameHistoryComplete。客户端不能提交这些字段；账号信息接口只使用可信的微信 OpenID 读取本人资料。不需要新增集合或调整数据库权限。

## 手动部署

1. 在微信开发者工具中确认选择当前项目的云开发环境。
2. 右键 cloudfunctions/userService **整个文件夹**，选择“上传并部署：云端安装依赖（不上传 node_modules）”。
3. 等待部署成功后重新编译小程序。前端新增页面会随本地编译生效。

## 验收

1. 进入“我的”，确认主页不再显示学校名；点击加入日期旁的小箭头。
2. 未认证、审核中或已撤回时学校显示“未认证”；认证通过后显示认证学校和“已认证”标识。
3. 修改昵称并成功保存，重新进入账号页，次数增加 1，最后修改时间更新；退出重登后记录仍保留。
4. 仅修改简介、生日、头像或封面，次数及最后改名时间保持不变。
5. 页面不展示账号所在地及统计起点提示；ID账号配置及旧账号补齐见 [ID账号部署与补齐](ID账号部署与补齐.md)。
