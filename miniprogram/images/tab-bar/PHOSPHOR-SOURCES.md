Default variants use assets/bold/<name>-bold.svg; selected variants use
assets/fill/<name>-fill.svg. Source path geometry is retained. Fixed fills
replace currentColor for WeChat image rendering: #777C88 (default),
#4775FA (selected). No runtime library dependency is required.
