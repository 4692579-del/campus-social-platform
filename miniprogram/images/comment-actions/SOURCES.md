# 评论互动动效资源

按用户提供视频，以项目内矢量图形实现红心浮起、裂开和碎片动效。break-left.svg与break-right.svg为同一颗红心的锯齿切面，使用本地SVG渐变与高光，不含脚本、外链、字体或位图。

静态按钮沿用images/interface中的爱心及心碎图标；新增heart-solid.svg沿用heart-active.svg轮廓，仅填充项目原粉色#E34B76。点赞/取消在缩至最小时切换常驻的两层图标，避免更换图源闪烁。红心与碎片只绘制于被点击的心碎按钮上方，不遮挡点击，不参与正文高度布局。

动画由comments-sheet组件内WXSS与短时清理回调驱动。无云端、存储、相册或第三方动画依赖。
