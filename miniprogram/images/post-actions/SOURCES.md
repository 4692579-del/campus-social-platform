# 动态互动图标

来源为用户提供的 `爱心.svg`、`评论.svg`、`引用 (1).svg`、`分享.svg`。第三项按最新要求采用新版链环形引用图标。沿用各自图形，不替换评论区或底栏的其他资源。

- 统一24×24画布，在现有32rpx图标盒中显示。
- 根据实际轮廓消除原稿留白，并做光学校正：心形及分享箭头宽20.4、评论气泡19.4、引用19.8，视觉居中。
- 轮廓视觉线宽约1.78（24单位画布）。爱心、评论和引用原稿是填充轮廓，按原稿线厚补偿；分享沿用原始轮廓。
- 默认颜色 `#87919C`，与互动数字一致；点赞后沿用 `#E34B76`，仅换色，形状和尺寸保持一致。
- SVG不带背景、滤镜、字体或外部引用。
