# 动态互动图标

按用户最新提供的Threads互动栏截图重绘：圆润爱心、内部空白且尾部朝右下的评论气泡、双向循环箭头、朝右的纸飞机。取代此前独立SVG版本，仅用于共用square-post互动栏，评论区和底部导航图标不受影响。

- 统一24×24画布、2单位圆角描边，图标盒40rpx。
- 默认图标及数字为深灰#454745；点赞状态保持#E34B76，形状和尺寸一致。
- 数字28rpx、400字重，图标与数字间隔10rpx，各组间隔40rpx，前三组至少100rpx宽，左对齐排列。
- 点赞、评论、引用使用真实计数，过万按一位小数截取显示“万”，过亿显示“亿”；前三项零计数保留0，分享项按截图只展示纸飞机。
- 第三个循环箭头继续触发现有引用发布，分享仍未开放。
- SVG不含背景、滤镜、字体或外部引用。

- 按后续视觉反馈，爱心轮廓围绕中心单独放大10%，同步反向补偿描边，保持实际线宽与其他三项一致；图标盒、数字位置及间距保持不变，普通/点赞态共用同样几何。

- 纸飞机按后续单独提供的截图重新描绘：接近等宽等高的圆润箭头、较浅的左侧内凹、贯穿中线和圆钝尖端；保持40rpx图标盒、2单位实际线宽及#454745颜色，不修改其他图标和点击行为。

- 引用成功态quote-active.svg与普通态保持完全相同几何、尺寸和描边，仅改为主题蓝#4775FA；按当前账号已发布的真实引用关系显示，不以点击入口或全局引用数量点亮。

- 首页、动态详情页及个人主页“动态”标签的点赞动效按用户视频实现粉紫环形爆发、七组双粒子和爱心回弹；新增like-filled.svg沿用现有爱心轮廓及描边，仅填充#E34B76，启用动效时的成功点赞使用，其他未启用的列表保留原like-active.svg。动画为WXSS局部transform/opacity及短时圆环描边动画，不使用位图或逐帧列表更新。
